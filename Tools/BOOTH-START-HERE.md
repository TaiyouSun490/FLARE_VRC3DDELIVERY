# FLARE Core 0.2.5

## 日本語

1. `KNOWN-ISSUES.md` の対応範囲・既知の問題を確認してください。
2. Unity **2022.3.22f1** の VRChat Worlds / Built-in プロジェクトを用意します。
3. **VRChat Worlds SDK 3.10.4（UdonSharp同梱）** と **lilToon 2.3.4** を先に導入します。本ZIPには同梱していません。
4. `FLARE-Core-0.2.5.unitypackage` を開き、すべてをImportします。
5. `USER-GUIDE-JA.md` に従い、CreatorでRAC2を書き出し、公開HTTPSへ配置して、同梱Prefabから読み込みます。

Unityの `Tools > FLARE > User Guide...` からも使い方を開けます。CreatorのLanguage / 言語で日本語・英語を切り替えられます。

アバター・衣装・テスト用RAC2・配信用ホストは含まれません。PC向けです。既存ワールドへ導入する前にバックアップしてください。

利用許諾・価格・サポート窓口は販売者のBOOTH掲載条件をご確認ください。このREADMEは利用許諾を定めるものではありません。

## English

1. Read `KNOWN-ISSUES.md` before use.
2. Prepare a VRChat Worlds project using **Unity 2022.3.22f1 / Built-in**.
3. Install **VRChat Worlds SDK 3.10.4 (includes UdonSharp)** and **lilToon 2.3.4** first. They are not included in this ZIP.
4. Import all contents of `FLARE-Core-0.2.5.unitypackage`.
5. Follow `USER-GUIDE-EN.md` to export RAC2, host it on public HTTPS, and load it using an included prefab.

Use `Tools > FLARE > User Guide...` for the in-project guide. Choose Japanese or English with the Creator's Language selector.

Avatars, clothing, test RAC2 files and hosting are not included. Intended for PC. Back up an existing world before importing.
