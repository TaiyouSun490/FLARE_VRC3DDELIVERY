# RAC2 PC描画負荷の参考ランク

Creatorでルートを選択すると、色と記号付きのExcellent / Good / Medium / Poor / Very Poorを表示します。読み込み完了後のImagePadにも同じ描画項目の参考評価を表示します。

これはVRChatアバターのアップロード可否やSDK総合ランクではありません。RAC2で出力・復元される有効なメッシュ／マテリアルスロット／粒子システム数／最大粒子数を測り、最も重い項目を採用します。VATは復元後に通常のMeshRendererとして動作するため、元のSkinnedMeshRenderer数とは評価対象が異なります。無効オブジェクトも数える公式アバター評価とは母集団も異なります。

PCの閾値は2026-09-21時点の公式資料に対応:
https://creators.vrchat.com/avatars/avatar-performance-ranking-system/

三角形数は32,000以下がExcellent、70,000以下がGood、70,000超がVery Poor。三角形単独でMedium/Poorにはなりません。マテリアルスロットは4/8/16/32、復元後の通常メッシュは4/8/16/24、粒子システムは0/4/8/16、最大粒子数は0/300/1000/2500を各ランクの上限として使います。

テクスチャ総メモリ・シェーダー計算量・粒子メッシュ三角形・一時RAM・PhysBoneなどは未評価です。VAT位置/法線テクスチャの生データ容量はCreatorで別に概算表示します。Very Poorでも書き出せますが、受信端末のFPSや安全性を保証しません。

## 技術上限と互換性

PC向け共通上限をRac2Capacityに定義: 250,000頂点、1,500,000インデックス（500,000三角形）、保存・展開後それぞれ128 MiB。これはパフォーマンスの推奨値ではなくデータ検証の上限です。16レンダラー/64マテリアル/4粒子エミッター、VATの行数・フレーム数などの既存制限は継続します。

v3順次復元も65,535頂点を超えるメッシュではUInt32を使用。ファイル形式は変えず、古いファイルも受け付けます。拡張上限を使ったファイルは古いローダーでは拒否されるので、書き出し側だけでなくワールド側も更新してください。今回の変更は作業プロジェクトに反映しており、以前の配布UnityPackageは未更新です。

## 検証

ランク境界値と65,535 / 65,536 / 70,000頂点でのUnity Meshインデックス往復、Udonコンパイルを確認。シリウスの69,803三角形・42,683頂点・11マテリアル・11 VATノードを削減せず書き出し成功。参考評価はMedium、VAT概算24.1 MiB、保存ファイル44,913,632 bytes。VRChat実機のダウンロード経路とピークメモリ、出現時の見た目・FPSは未検証。
