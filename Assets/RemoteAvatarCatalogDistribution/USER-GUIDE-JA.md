# FLARE — 使い方（日本語）

[English](USER-GUIDE-EN.md)

FLAREは、公開HTTPS URLからRAC2形式の3D展示物を読み込み、VRChatワールド内に表示するPC向けギミックです。モデル、VATアニメーション、対応パーティクルを1つのファイルにまとめられます。

RAC2はアバターそのものやUnityの任意のスクリプトを配信する形式ではありません。VATは頂点の動きを記録した再生用データです。読み込み後にAnimatorやPhysBoneが動作するわけではありません。

## 1. 導入前の準備

検証に使っている構成:

- Unity 2022.3.22f1、Built-in Render Pipeline
- VRChat Worlds SDK 3.10.4（UdonSharp同梱）
- lilToon 2.3.4
- Windows / PC向けワールド

VCCでWorldsプロジェクトを用意し、Worlds SDKとlilToonを先に導入してください。第三者製SDK・シェーダー、アバター、衣装、CDN契約は同梱されません。Quest / Android、URP / HDRPは対応確認の対象外です。

既存プロジェクトはバックアップしてください。同じGUIDの旧FLAREファイルがあれば、unitypackageのインポートで更新されます。新しい別系統のギミック版からのダウングレードには使わないでください。

## 2. ワールドに設置して読み込む

1. Unityの `Assets > Import Package > Custom Package...` から配布されたunitypackageをインポートします。
2. `Assets/RemoteAvatarCatalogDistribution/Prefabs/RAC2-ImagePad.prefab` をシーンの床位置へドラッグします。
3. 初回は付属Prefabの参照・子オブジェクトを変更せずに使います。
4. VRChat SDKからPC向けワールドとしてビルドして、VRChatで確認します。SDKのビルド手順はSDK側の案内に従ってください。
5. パネルに公開HTTPSの `.rac2` ファイルURLを貼り付け、**RAC2を読み込む**を押します。
6. 読み込み完了後、モデルが出現します。**再試行**は直前のURLを再読込し、**表示を消す**は現在の展示を消します。

配信ドメインがVRChatの信頼済み一覧に含まれない場合、利用者側のVRChat設定で `Allow Untrusted URLs` を有効にする必要があります。管理者がワールドだけで全員分を有効化する設定ではありません。

配布版にはマリア・シリウス等のアバターや、その確認用URLを使用する権利は付属しません。自分が配信を許可されているデータのURLを使ってください。RAC2サンプルURLが空でも故障ではありません。

### Prefabの選び方

| Prefab | 用途 |
| --- | --- |
| RAC2-ImagePad | モデル・VAT・パーティクルの表示。通常はこちら |
| RAC2-ImagePad-Pedestal | 表示に加えて商品情報とアバター試着 |
| RAC2-Product-Pedestal | 商品情報とアバター試着のみ。3Dモデルは復元しない |

試着は別途VRChatへアップロード済みのアバターを指定する機能です。RAC2モデルを着用アバターへ変換するものではありません。

## 3. 言語を選ぶ

- Creator上部の `Language / 言語` で `日本語` または `English` を選びます。初回はOS言語を参考にし、選択はUnity Editorの設定として保存されます。
- `Tools > FLARE > User Guide...` またはCreatorの**使い方**から、選択言語の説明書を開けます。
- ワールドのImagePadは `RuntimeRacImagePadControllerV2` のInspectorにある `Use Japanese` をオンで日本語、オフで英語に設定します。設定後にワールドをビルドしてください。
- ペデスタルの表示言語は `Rac2ProductController` の同名設定で選びます。統合版を英語にする場合は両方をオフにします。
- 独自UIを作る場合、ImagePadの公開イベント `SetJapanese` / `SetEnglish` にボタンを接続できます。プレイヤー間では同期されません。
- マテリアルの出現エフェクト欄は、周囲と混在しないようlilToon Inspector側の言語設定に従います。

Unityの固定メニュー名、ファイル名、API名、公式の性能ランク名（Excellent～Very Poor）は共通表記です。Consoleの技術診断や第三者ツールのエラーは原文を残します。日本語フォントの表示はビルド後にも確認してください。既存シーンの独自ラベルまでは自動翻訳しません。

## 4. モデルとパーティクルを1つのRAC2にする

1. Hierarchyに展示物のルートを1つ作ります。モデルとパーティクルを、その子にまとめます。モデル自身をルートにしても構いません。
2. そのルートを選び、`Tools > FLARE > RAC2 Creator...` を開きます。右クリックの `FLARE > Create RAC2 from this object...` からも開けます。
3. **展示物のルート**に正しいオブジェクトが入っていることを確認します。必要なら**選択中のオブジェクトを使用**を押します。
4. モデル数・マテリアル数・パーティクル数と、描画負荷の参考ランクを確認します。
5. **保存後のブースを見る**で配置を確認します。保存時にモデル形状を基準に床置き・中央寄せします。ルートのピボットを足元へ手修正する必要はありません。
6. 静止展示ならアニメーションクリップは空欄のままにします。動きを付ける場合は次の節を設定します。
7. 必要に応じてパーティクル、カタログ情報、持ち運びを設定します。
8. **RAC2を作成…**で保存先を選びます。完了ダイアログのメッシュ数・VATメッシュ数・エミッター数を確認します。

Creatorはファイルを書き出します。CDNへ自動アップロードする機能ではありません。通常の作成に `FLARE > Developer` 内のテストランナー、旧エクスポーター、インストーラーは不要です。

### アニメーションとPhysBone

- **アニメーションクリップ**に再生したいClipを指定します。空欄では静止版になり、PhysBoneの揺れも入りません。
- **VATのフレームレート**と**ループ**を指定します。1ファイルで1つのClipを扱います。
- **VATの法線を焼き込む**をオンにすると、変形に応じた法線も記録します。ファイル容量は増加します。
- 揺れを含めるには**PhysBoneを含める**をオンにします。現実装はSDK 3.10.4のオフライン計算に対応しています。互換性のないSDKでは停止します。
- **開始姿勢の安定化**は収録前の待ち時間です。**ループ末尾の揺れ補間**は物理のずれだけを先頭へ近づけます。Clip自体の移動や姿勢の段差は直しません。
- ルート内のPhysBone Colliderは対象ですが、外部ワールドとの衝突やプレイヤーが触る・掴む操作は記録できません。ClipによるPhysBone設定や有効状態の変更も未対応です。
- MA衣装ではModular Avatar / NDMFを導入してください。検証した組合せはMA 1.18.7 / NDMF 1.14.8です。書き出し用コピーで衣装を構築し、元のモデルは変更しません。
- 完了時の**VATメッシュ**が0なら、そのファイルにVATは入っていません。

### ブースとパーティクル

基本ブースは横3m × 奥行3m × 高さ2.7mです。緑がブース、青が床、黄・赤がモデルの範囲です。クリップ指定時の確定判定にはVAT全フレームの範囲を使います。

超過時は表示された寸法を確認し、**大きすぎる要素を選択**からモデルやアニメーションを調整します。パーティクルの位置・移動範囲は床置き・中央寄せ・寸法判定から除外され、ブース外の粒子は再生時に隠れます。

パーティクルはUnityの全モジュールをそのまま再現するものではありません。基本的な点・球・円錐・箱、ビルボード・メッシュ、アルファ・加算合成、重力・色変化・回転・フリップブックが対象です。Noise / Collision / Trails / Sub Emitters / Lightsは非対応です。Simulation SpaceはLocal、寿命・重力・放出率は定数にしてください。その他の未対応設定はCreatorのエラーで確認してください。

### カタログ情報と持ち運び

**カタログ情報を含める**をオンにすると、商品名・作者名・HTTPS商品URLなどを保存します。試着を使う場合は有効な `avtr_...` のBlueprint IDと試着許可を設定し、ペデスタル付きPrefabで読み込みます。

**持ち運びを許可**をオンにすると、メタデータへ保存され、コライダーも有効になります。読み込み・再読み込みでは初期位置へ戻ります。

## 5. ファイルを配信する

自分のWebサーバー、CDNなどにRAC2を置き、認証・Cookie・HTML閲覧ページを介さず、ファイル本体を直接返すHTTPS URLを用意します。リダイレクトなしで `200 OK` を返す構成にしてください。Content-Typeの推奨値は `application/octet-stream` です。

Creatorの**ファイルを圧縮**はLZ4の可逆圧縮です。転送量は減りますが、Udonでの展開に時間がかかります。**同一テクスチャを共有**には読み込み側0.2.4以降が必要です。

ホスティング側にもファイルサイズ制限があります。128 MiBはFLAREの安全上限であり、配信サービスが同じサイズを許可する保証ではありません。差し替えがキャッシュに残る場合は、新しいファイル名のURLで確認してください。

## 6. 負荷・出現エフェクト・上限

自動負荷調整は既定でオンです。読み込み中のFPSを参考に処理量を連続調整しますが、Unityのメッシュ適用やGPUへの転送を完全に分割できるわけではありません。常に無停止になる保証はありません。

出現エフェクトは `Rac2RuntimeLoader` の `Reconstruction` 設定で調整します。Durationは秒数、Block Sizeはブロックの大きさ、Edge Colorは発光色、Inflationは縁の膨らみです。Inflationを0にすると膨らみを無効化できます。詳しくは `RECONSTRUCTION-JA.md` を参照してください。

| 項目 | 現実装の上限 |
| --- | --- |
| メッシュ / マテリアル | 16 / 64 |
| パーティクル | 4エミッター、各32粒子 |
| 合計頂点 / 三角形 | 250,000 / 500,000 |
| 保存・展開後のファイル | 各128 MiB |
| VAT | 2～240フレーム、1～60 FPS |
| ペデスタル単体版の入力 | 64 MiB |

上限内でも快適に動くとは限りません。Mesh Baker等での事前最適化を推奨します。過剰なメッシュ・マテリアル・頂点・テクスチャを減らしてください。最適化はVATを書き出す前に行います。参考ランクはVRChat SDKのアバター総合ランクではありません。

## 7. 困ったとき

| 症状 | 確認すること |
| --- | --- |
| 動かない・揺れない | Clip指定と完了時のVATメッシュ数。読み込み後のライブPhysBoneではありません |
| 衣装が追従しない | MA/NDMFの導入、Missing Script、Constraintの参照先、元のアニメーション |
| ブースより大きい | モデル/VATの全体寸法を縮小。ピボット移動では解決しません |
| META範囲エラー | 更新済みCreatorで再作成。旧ファイルのURL差し替えも確認 |
| 目・色・質感が元と違う | lilToonの全機能を再現する形式ではありません。主テクスチャ・法線・Opaque/Cutoutの対応範囲を確認 |
| ダウンロードできない | HTTPS、直接ファイルURL、公開権限、ホストのサイズ制限、Allow Untrusted URLs |
| 読み込みが重い | メッシュ/画像/VATフレームを削減。自動負荷調整オン、必要に応じて非圧縮で比較 |

書き出しエラーの**技術情報を表示**またはUnityのConsoleから詳細を取得できます。問い合わせ時にはUnity/SDK/lilToonのバージョン、操作手順、エラー全文を添えてください。再配布できないアバターデータは送らないでください。

## 8. 現時点の注意

シリウスの確認データで「読み込み後に虹彩・瞳孔が見えない」事象が報告されており、原因・修正は未確定です。特定モデルやlilToon設定の見た目を完全再現する保証はありません。販売前に実際の配布パッケージを新規プロジェクトへ導入し、VRChatでJP/ENの表示、読み込み、VAT、パーティクル、出現演出を確認してください。
